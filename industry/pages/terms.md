页首说明：

> 本站收集马来西亚餐饮业相关的公开消息，用模型写成中文标题、摘要和推荐理由，原文版权归各来源所有。网站、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 本站是什么

本站自动收集政府机构、报纸、平台和餐饮媒体公开发布的消息，挑出与餐饮经营相关的，写成中文摘要，并整理成日报、周报和月报。

本站不是政府机构，也不是持牌的法律、税务或会计顾问，站内内容不构成专业意见。涉及法规、税务、执照准证或合同的决定，请以原文和主管机构的正式公告为准，必要时咨询持牌专业人士。

## 2. 内容与版权

- 站内的标题、摘要和推荐理由由模型根据公开来源生成，可能有误或遗漏，重要信息请点开原文核对。
- 对第三方的报道和公告，本站只展示标题、来源名、简短摘要和原文链接，不转载全文。每条内容都注明来源并链接原文，原文版权归各来源所有。
- 本站自己编写的内容（日报、周报、月报的编排与导语）版权归本站。欢迎分享链接；整篇转载或用于商业用途，请先联系我们。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过[反馈页](/feedback)或来信联系我们，我们收到后会尽快处理。

## 4. 精选与赞助

- 哪些消息入选精选、怎么排序，只由固定的评分标准和入选门槛决定，不接受付费改变。
- 周报可能设有赞助位，赞助内容会清楚标明“赞助”。赞助商不能影响哪些消息入选、怎么排序和怎么写。
- 本站不卖课程，不卖加盟。

## 5. 使用本站的内容与数据

可以自由用于个人阅读和组织内部参考；在注明出处并附上链接的前提下，可以引用少量内容。批量抓取后公开转载、再分发，或用于商业产品，请先取得我们的书面同意。

## 6. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

## 7. 免责

本站按“现状”提供，不保证内容完整、准确、及时和持续可用。在法律允许的范围内，本站及运营者不对因使用本站内容而产生的直接或间接损失承担责任。

## 8. 适用法律与更新

本规则受马来西亚法律管辖。本规则更新时会在本页公布新版本并更新生效日期；更新后继续使用本站，即表示接受新版本。
