
【马来西亚餐饮领域写作规则 — 本平台读者是马来西亚华文餐饮经营者，严格遵守】

1. 歧义默认值：以下词一律按马来西亚餐饮经营的含义理解和翻译：
   - SST = 销售与服务税（Sales and Service Tax）
   - Minimum wage / gaji minimum = 最低薪金
   - F&B = 餐饮；outlet = 分店、门店；operator = 业者
   - Stall / gerai = 档口；hawker / penjaja = 小贩；food court / medan selera = 食阁；kopitiam / kedai kopi = 咖啡店；mamak = 嘛嘛档
   - Delivery platform = 外卖平台；rider = 外送员；commission（平台语境）= 佣金；MDR = 刷卡或电子支付手续费
   - Foreign worker / pekerja asing = 外劳；levy（外劳语境）= 外劳人头税
   - Premises licence / lesen premis = 营业执照；signboard licence = 招牌执照
   - e-Invoice / e-Invois = 电子发票
   - Subsidised cooking oil / minyak masak bersubsidi = 津贴食用油
   - Typhoid injection = 伤寒针；food handler training = 食物处理课程

2. 机构缩写保留英文，首次出现时括注中文，之后选一种写法保持一致：
   - LHDN（内陆税收局，英文 IRB，新标识 HASiL）、KWSP（公积金局，英文 EPF）、PERKESO（社险机构，英文 SOCSO）、EIS（就业保险）、KPDN（国内贸易与生活成本部）、KKM（卫生部，英文 MOH）、JAKIM（伊斯兰发展局）、KESUMA（人力资源部）、JTKSM（劳工局）、Imigresen（移民局）、BNM（国家银行）、DOSM（统计局）、MOF（财政部）、SSM（大马公司委员会）、SME Corp（中小企业机构）
   - 地方政府用中文名，首次括注缩写：吉隆坡市政局（DBKL）、八打灵再也市政厅（MBPJ）
   - 已有通行中文名的（公积金局、社险机构、移民局、国家银行、统计局、财政部），可以只用中文名

3. 马来文和英文专有名词保留原文，必要时括注中文：
   - 法令与政策名称：Perintah Gaji Minimum（最低薪金法令）、Akta Kerja 1955（1955 年雇佣法令）
   - 官方系统：MyInvois、MyHalal、e-Filing、i-Akaun
   - 援助计划名称保留原文，不要意译成另一个名字
   - 公司与品牌名：Grab、foodpanda、ShopeeFood、Touch 'n Go 等一律保留原文

4. 金额、数字、日期一字不改保留：
   - 令吉写 RM 加阿拉伯数字：RM1,700、RM500,000；百万以上可以写成 RM150万，但必须等值，不能改写成“一百多万”“数百万”这类模糊说法
   - 外币照原文币种（US$、S$、人民币），不要换算成令吉
   - 比例、区间、期限照原文：6%、8% 至 10%、30 天内
   - 日期照原文的精度：原文只写到月份，就只写月份

5. 用词：
   - 用“开业”，不用“开店”；只有特指实体店面时才用“开店”（例如“从夜市摊到开店”“连锁开店节奏”“在外卖平台开店”），每天营业前的“开店前检查”照用
   - 用“最低薪金”，不用“最低工资”
   - “业者”“老板”指经营者，“食客”“顾客”指消费者，不要混用
