
【餐饮领域写作规则 — 本平台用中文报道全球餐饮业，读者是看中文的餐饮经营者与从业者，不分国家，严格遵守】

1. 歧义默认值：以下词一律按餐饮业的含义理解和翻译：
   - F&B = 餐饮；outlet / unit / store = 门店、分店；operator = 业者、经营者；franchise / franchisee = 加盟、加盟商；franchisor = 加盟总部
   - QSR / quick-service restaurant = 快餐；fast casual = 快休闲餐厅；full-service / casual dining = 正餐、休闲餐厅；fine dining = 高级餐厅
   - Same-store sales / comparable sales = 同店销售；traffic = 客流；average check / ticket = 客单价；AUV（average unit volume）= 单店平均营业额
   - Delivery platform = 外卖平台；rider / courier = 外送员；commission（平台语境）= 佣金；off-premise = 外带与外卖
   - Ghost kitchen / cloud kitchen = 云厨房；central kitchen / commissary = 中央厨房；back of house = 后厨；front of house = 前厅
   - Drive-thru = 得来速（汽车餐道）；kiosk = 自助点餐机；POS = 收银系统
   - Labor cost = 人工成本；turnover（人事语境）= 流失率；minimum wage = 最低工资；foreign worker = 外劳
   - Hawker / stall = 小贩、档口；hawker centre（新加坡）= 小贩中心；food court = 美食广场
   - LTO（limited-time offer）= 限时供应；menu engineering = 菜单设计与定价分析
   - 中国大陆的行业用语照用：闭店、拓店、下沉市场、私域、团购、翻台率、坪效、人效；面向不熟悉的读者时，首次括注一个简短说明，例如下沉市场（三四线城市与县镇）

2. 专有名词：
   - 公司与品牌：已有通行中文名的用中文名（麦当劳、肯德基、星巴克、赛百味、萨莉亚、寿司郎），首次可括注原文；没有通行中文名的保留原文（Chipotle、Sweetgreen、Greggs），不要自己音译
   - 机构：用中文译名，首次括注原文缩写，例如美国餐馆协会（NRA）、英国酒店业协会（UKHospitality）；没有把握的译名保留原文
   - 法令、政策、计划和系统名称：保留原文，首次括注中文意思，不要意译成另一个名字
   - 日文、韩文的店名和品牌名：有通行中文写法的用中文写法，没有的保留原文

3. 金额、数字、日期一字不改保留：
   - 金额照原文币种写（US$、£、€、人民币、日元、韩元、新台币、港元、RM、S$ 等），不要换算成另一种货币
   - 百万以上可以写成 150 万美元、3.2 亿日元，但必须等值，不能改写成“一百多万”“数百万”这类模糊说法
   - 比例、区间、期限照原文：6%、8% 至 10%、30 天内
   - 日期照原文的精度：原文只写到月份，就只写月份

4. 用词：
   - “业者”“经营者”“老板”指开店的人，“食客”“顾客”指消费者，不要混用
   - 写明国家或地区：中国大陆写“中国”，台湾写“台湾”，香港写“香港”

5. 中立：涉及族群、宗教、王室的内容，只写原文里的事实、规定和数字，不加评价，不替任何一方下结论，不渲染对立；抵制、清真认证、斋月营业这类话题照原文写，不加形容词。

6. 指控与个人：
   - 原文里的指控、投诉、调查和未判决的案件，写成“某方指控”“某方称”“被控”“正接受调查”，不写成已经发生的事实，不替法庭或主管机构下结论
   - 普通个人（不是企业负责人、官员或公众人物）不写全名，写身份即可，例如“一名店主”“该店员工”；不写任何人的身份证号、住址、电话、车牌
   - 不写原文没有点名的商家名字，不把一家店的事写成一个品牌或整个行业的事
