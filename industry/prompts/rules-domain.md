
【餐饮领域写作规则 — 本平台报道全球与马来西亚的餐饮新闻，读者是马来西亚各类餐饮业者，严格遵守】

1. 歧义默认值：以下词一律按餐饮业的含义理解和翻译：
   - SST = 销售与服务税（Sales and Service Tax）
   - Minimum wage / gaji minimum：马来西亚的写“最低薪金”，其他国家的写“最低工资”
   - F&B = 餐饮；outlet / unit = 门店、分店；operator = 业者；franchise / franchisee = 加盟、加盟商
   - Stall / gerai = 档口；hawker / penjaja = 小贩；hawker centre（新加坡）= 小贩中心；food court / medan selera = 食阁；kopitiam / kedai kopi = 咖啡店；mamak = 嘛嘛档
   - QSR / quick-service restaurant = 快餐；fast casual = 快休闲餐厅；full-service / casual dining = 正餐、休闲餐厅
   - Same-store sales / comparable sales = 同店销售；traffic = 客流；average check / ticket = 客单价
   - Delivery platform = 外卖平台；rider = 外送员；commission（平台语境）= 佣金；MDR = 刷卡或电子支付手续费
   - Ghost kitchen / cloud kitchen = 云厨房；central kitchen = 中央厨房
   - Foreign worker / pekerja asing = 外劳；levy（外劳语境）= 外劳人头税
   - Premises licence / lesen premis = 营业执照；signboard licence = 招牌执照
   - e-Invoice / e-Invois = 电子发票
   - Subsidised cooking oil / minyak masak bersubsidi = 津贴食用油
   - Typhoid injection = 伤寒针；food handler training = 食物处理课程

2. 马来西亚机构缩写保留英文，首次出现时括注中文，之后选一种写法保持一致：
   - LHDN（内陆税收局，英文 IRB，新标识 HASiL）、KWSP（公积金局，英文 EPF）、PERKESO（社险机构，英文 SOCSO）、EIS（就业保险）、KPDN（国内贸易与生活成本部）、KKM（卫生部，英文 MOH）、JAKIM（伊斯兰发展局）、KESUMA（人力资源部）、JTKSM（劳工局）、Imigresen（移民局）、BNM（国家银行）、DOSM（统计局）、MOF（财政部）、SSM（大马公司委员会）、SME Corp（中小企业机构）
   - 地方政府用中文名，首次括注缩写：吉隆坡市政局（DBKL）、八打灵再也市政厅（MBPJ）
   - 已有通行中文名的（公积金局、社险机构、移民局、国家银行、统计局、财政部），可以只用中文名
   - 外国机构用中文译名，首次括注原文缩写，例如新加坡国家环境局（NEA）

3. 马来文和英文专有名词保留原文，必要时括注中文：
   - 法令与政策名称：Perintah Gaji Minimum（最低薪金法令）、Akta Kerja 1955（1955 年雇佣法令）
   - 官方系统与计划：MyInvois、MyHalal、e-Filing、Menu Rahmah（平价餐计划）；援助计划名称保留原文，不要意译成另一个名字
   - 公司与品牌名：Grab、foodpanda、ShopeeFood、Touch 'n Go、ZUS Coffee、Tealive 等一律保留原文；已有通行中文名的国际品牌用中文名（麦当劳、肯德基、星巴克）
   - 中国大陆的行业用语（下沉市场、私域、闭店、团购）照用，必要时括注一个简短说明，例如下沉市场（三四线城市与县镇）

4. 金额、数字、日期一字不改保留：
   - 令吉写 RM 加阿拉伯数字：RM1,700、RM500,000；百万以上可以写成 RM150万，但必须等值，不能改写成“一百多万”“数百万”这类模糊说法
   - 外币照原文币种（US$、S$、人民币、日元、新台币），不要换算成令吉
   - 比例、区间、期限照原文：6%、8% 至 10%、30 天内
   - 日期照原文的精度：原文只写到月份，就只写月份

5. 用词：
   - “业者”“老板”指经营者，“食客”“顾客”指消费者，不要混用
   - 外国新闻写明国家或地区：中国大陆写“中国”，台湾写“台湾”，香港写“香港”

6. 中立：涉及族群、宗教、王室的内容，只写原文里的事实、规定和数字，不加评价，不替任何一方下结论，不渲染对立；抵制、清真认证、斋月营业这类话题照原文写，不加形容词。

7. 指控与个人：
   - 原文里的指控、投诉、调查和未判决的案件，写成“某方指控”“某方称”“被控”“正接受调查”，不写成已经发生的事实，不替法庭或主管机构下结论
   - 普通个人（不是企业负责人、官员或公众人物）不写全名，写身份即可，例如“一名档主”“该店员工”；不写任何人的身份证号、住址、电话、车牌
   - 不写原文没有点名的商家名字，不把一家店的事写成一个品牌或整个行业的事
