
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：品牌名 / 平台名 / 机构名 / 政策或计划名。
2. 原标题已经清楚点出主体的：外文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是泛称 / 编号 / 没信息量的 teaser（如 "Press Release"、"Weekly Update"、"Announcement"、"重磅消息"）时，结合【来源】和正文把主体和具体内容补进标题。例：原标题 "Monthly Index" + 来源 "某国餐馆协会" + 正文写明是 7 月餐饮营业额指数 → "某国餐馆协会公布 7 月餐饮营业额指数"（用正文里真实的协会名代替“某国餐馆协会”）。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或品牌时，用上位词（如"一家连锁""外卖平台"）兜底，绝不凭"行业常识"编一个具体机构 / 品牌 / 日期 / 金额。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / 专访 / 评论这类解释、分析、教程或观点标题，中文标题必须保留这个类型；不能因为正文谈到一项已经存在的政策或新数据，就改写成“宣布 / 推出 / 实施 / 生效”。只有原标题明确宣布了公布、推出、实施或生效，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的品牌、平台、机构名。
   例：原标题 "How rising wages are squeezing pizzeria margins" → "工资上涨如何压缩披萨店的利润"，不能写成 "政府宣布上调最低工资"。
   例：原标题 "Why more merchants are leaving the platform" + 正文明确是 DoorDash → "为何越来越多商家退出 DoorDash"，不能只写成缺主体的 "为何越来越多商家退出平台"。
6. 标题要点出国家或地区，让读者一眼知道是哪里的事；主体已经表明地区的（如"新加坡小贩中心""日本萨莉亚"）不必重复，全球性的事不加。
   例：原标题 "Ramen chains raise prices as rice costs climb" + 正文写的是日本 → "日本拉面连锁因米价上涨而加价"。
7. 标题写成陈述句：谁做了什么、主张什么，或者结果是什么。原标题是设问、比喻或口号（“……是续命药还是慢性毒药？”“……不是救命稻草”“为什么……垮掉”）时，标题写正文给出的答案；How / Why 类标题可以保留“如何”“为何”，但不以问号结尾。标题不对读者说“你”，不写成指令（“别再……”“……该做的是……”）；原标题是指令时，写成“某人认为……”。标题里的外国专名读者不认识时，加两三个字说明它是什么（“点餐系统 GloriaFood”）。
