
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 平台名 / 品牌名 / 政策或计划名。
2. 原标题已经清楚点出主体的：英文或马来文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是泛称 / 编号 / 没信息量的 teaser（如 "Garis Panduan Teknikal"、"Kenyataan Media"、"Pengumuman"、"重磅消息"）时，结合【来源】和正文把主体和具体内容补进标题。例：原标题 "Garis Panduan Teknikal" + 来源 "内陆税收局 LHDN · 公告与文告" + 正文写明是海外资本资产处置利得的税务指南修订 → "内陆税收局修订海外资本资产处置利得的税务指南"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或品牌时，用上位词（如"地方政府""外卖平台"）兜底，绝不凭"行业常识"编一个具体机构 / 品牌 / 日期 / 金额。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / 专访 / 评论这类解释、分析、教程或观点标题，中文标题必须保留这个类型；不能因为正文谈到一项已经存在的政策或新数据，就改写成“宣布 / 推出 / 实施 / 生效”。只有原标题明确宣布了公布、推出、实施或生效，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、平台、品牌名。
   例：原标题 "How the minimum wage hike is squeezing kopitiam margins" → "最低薪金上调如何压缩咖啡店利润"，不能写成 "政府宣布上调最低薪金"。
   例：原标题 "Why more merchants are leaving the platform" + 正文明确是 foodpanda → "为何越来越多商家退出 foodpanda"，不能只写成缺主体的 "为何越来越多商家退出平台"。
