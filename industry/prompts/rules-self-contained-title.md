【标题规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题点出核心主体（品牌、平台、机构、政策或计划名）和是哪里的事；原标题只是泛称或没有信息量时，用【来源】和正文补上。
2. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构或品牌时，用上位词（如"一家连锁""外卖平台"）兜底，绝不凭"行业常识"编一个具体机构 / 品牌 / 日期 / 金额。
3. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / 专访 / 评论这类解释、分析、教程或观点标题，不能因为正文谈到一项已经存在的政策或新数据，就改写成“宣布 / 推出 / 实施 / 生效”。只有原文明确宣布了公布、推出、实施或生效，中文标题才能使用对应动作。
