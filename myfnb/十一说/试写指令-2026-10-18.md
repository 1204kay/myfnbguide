## 3. 试写（两个模型，同一批材料）

材料：7 期来自公开日报 10-11 到 10-17 每天的收录（`--day`），13 期来自参考库的主要书架（`--shelf`，用书架下故事的**原文**，不用故事本身），覆盖人手、成本、外卖、定价、客流（HANDOFF §9.0「上线顺序」）。

先预览（不调模型），看每一行的候选数；某个书架是 0 篇，换成同一大类里另一个有候选的书架（`modules/reference/situations.ts` 里同一 `category` 的），在报告里写明换了哪个：

```bash
TRIAL --model deepseek-flash-think \
  --day 2026-10-11 --day 2026-10-12 --day 2026-10-13 --day 2026-10-14 --day 2026-10-15 --day 2026-10-16 --day 2026-10-17 \
  --shelf busy-no-profit --shelf pricing --shelf waste --shelf delivery-margin --shelf labor-costs \
  --shelf hiring --shelf retention --shelf regulars --shelf slow-weekdays --shelf ticket-size \
  --shelf rush-chaos --shelf opening-cost --shelf not-breaking-even
```

然后同一条命令加 `--apply --max-calls 220` 正式跑 DeepSeek。跑完会打印结果目录（`/out/<时间>-deepseek-flash-think`，在服务器上是 `/tmp/myfnb-trial/<同名>`）。再用**同一批材料**跑 Claude：

```bash
TRIAL --model claude-sonnet-5-5 --from /out/<上一步的目录名> --apply --max-calls 220
```

命令会跑十几到几十分钟；用 `nohup … > /tmp/myfnb-trial/run-<模型>.log 2>&1 &` 放到后台，再看日志，免得 SSH 断开丢输出（HANDOFF §9.2 10/10 晚的教训）。

每期写出四个文件：`NN.md`（照页面顺序排好的一期，没过的也写出它的问题和拿掉的句子）、`NN.json`、`NN-原文.md`（编号过的原文，只给核对用，不上网站）；目录里还有 `index.md`（总表）和 `picks.json`。
